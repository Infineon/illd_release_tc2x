# iLLD Release TC2x


## Folder Structure
The `illd_release_tc2x` repo contains the following folders and files:

* `doc`      : Contains the TC2xx devices User Manual and iLLD Release note.
* `examples` : Contains the BaseFramework for all TC2xx devices and the BlinkyLed example project.
* `exe`      : Contains the installer for the iLLD package.
* `src`      : Contains the source code for TC2xx devices.
* `IFASLL202501`: contains the click license for TC3xx
* `Readme.md`: Contains information about folder structure, package usage and iLLD software
			   release version.


## Building the BlinkyLed Example
For instructions on integrating the BlinkyLed example files into the TC2xx Baseframework, please refer to the `Example_BlinkingLED.pdf` document.
